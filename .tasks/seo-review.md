- Семантика: один `<h1>`, логичная иерархия `<h2>`/`<h3>`, `<main>`, `<article>`, alt у изображений, width/height, lazy loading, preconnect к шрифтам.

## Средние проблемы

### 4. Контент и ключевые запросы
- H2/H3 почти не содержат прямых поисковых формулировок («уроки хэндпана в СПб», «хэндпан для начинающих», «боди-перкуссия обучение», «музыкант на мероприятие СПб»). Разговорные заголовки («Это проще, чем кажется») красивы, но слабо ранжируются. Стоит добавить 1–2 ключевых запроса в подзаголовки первого экрана разделов.
- Слово «боди-перкуссия» vs «телесная перкуссия» используются оба — хорошо для охвата, но в title/h1 оставить один основной вариант, второй распределить по H2/тексту.
- Нет текстового блока «FAQ» (хотя бы 3–5 вопросов) — низкочастотники + расширенные сниппеты.

### 5. Структурные данные
- Нет `BreadcrumbList`, `FAQPage`, `Person` (автор/преподаватель) — потенциально даёт расширенные результаты.
- Нет `aggregateRating` — не критично (нельзя фиктивно), но при наличии реальных отзывов добавить.

### 6. Навигация / якоря
- В меню есть пункт «Обо мне → #about», «Занятия → #how», но нет ссылок на #events («Живая музыка для события») и #contacts — важный коммерческий блок без внутренней ссылки.

## Мелкие замечания

- Нет favicon-ссылки в `<head>` (вид: `favicon.ico`, должен лежать в корне — проверить).
- Нет метатега `geo`/schema `geo` координат для LocalBusiness (плюс для локальной выдачи).
- Видео в `preload="none"` — ок для скорости, но поисковикам видео лучше индексируется с субтитрами/расшифровкой; добавить `<track kind="captions">` или текстовую транскрипцию рядом.
- Нет `sitemap.xml` и `robots.txt` в корне (проверить при деплое).
- `<html lang="ru">` — ок; добавить `og:image:alt` и `twitter:title/description` для полноты карточек.
